# Generation Log: control-taxonomy-cube

- **sim-id:** control-taxonomy-cube
- **Library:** Static SVG/HTML with hover tooltips (CSS grid + vanilla JS)
- **Bloom level/verb:** Understand / Classify
- **Learning objective:** Students will classify a given security control by both
  its function (preventive / detective / corrective / compensating) and its type
  (administrative / technical / physical), and give examples for each of the
  twelve combinations.

## Instructional-design decision

The spec is `infographic-svg`. For infographics, "interactive" means hover/click
reveals, not animation. I built a 4x3 classification matrix where each cell shows
one or two controls and a hover tooltip reveals a fuller list. This supports
classification practice (the core "Understand/Classify" objective) without any
moving parts.

## Implementation approach

- A CSS-grid matrix (`grid-template-columns: 130px 1fr 1fr 1fr`) generated by JS
  from a `cells[function][type]` data object, so content and layout are
  data-driven and easy to extend.
- Rows colored by function per spec: preventive #1565c0, detective #4caf50,
  corrective #ffa000, compensating #455a64. Column/row headers labeled.
- A mouse-following HTML tooltip (richer than `<title>`) shows the full example
  list per cell; click also fires it for touch devices. Tooltip is clamped to the
  viewport so it never runs off-screen.
- Legend below the grid keys the four function colors.
- Responsive: below 700px the grid collapses to a single column and column headers
  hide (per spec "rows stack to a vertical list").
- `control-taxonomy-cube.js` carries the `// CANVAS_HEIGHT` comment so
  `fix-iframe-heights.py` can size the iframe (the tool needs a `<sim-id>.js`).
