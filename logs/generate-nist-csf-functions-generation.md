# Generation Log: nist-csf-functions

- **sim-id:** nist-csf-functions
- **Library:** Static SVG with hover tooltips (inline SVG built/re-rendered by JS)
- **Chapter:** 13 — Organizational Security
- **Bloom level / verb:** Understand / Describe
- **Learning objective:** Name the six NIST CSF 2.0 functions, describe the role
  of each, and explain why GOVERN was elevated to a sixth function overseeing the
  operational cycle.

## Instructional-design decision

The spec is an `infographic-svg`. "Interactive" means hover/click reveals and a
responsive reflow, not animation. I built a wheel: GOVERN as a center hub, the
five operational functions as a colored donut ring, and a thin clockwise arrow
suggesting the Identify → Protect → Detect → Respond → Recover cycle. Hovering
or tapping any segment (or the hub) shows a one-sentence description in a tip
box. Below 600px the JS re-renders the same data as a numbered vertical list.
This matches an Understand-level objective without unnecessary motion.

## Implementation approach

- `main.html`: schema meta tag, bare `<main>`, a `#diagram` container, a tip
  box, and the CSF 2.0 caption. The SVG itself is generated by JS so the resize
  handler can swap between wheel and list.
- `nist-csf-functions.js`: `// CANVAS_HEIGHT:` comment, polar/arc-path helpers
  that compute the five ring segments and the clockwise direction arrow +
  arrowhead, hover/click/leave wiring to the tip box, and a `resize` listener
  that calls `renderWheel()` (>=600px) or `renderList()` (<600px).
- Colors per spec: GOVERN #1565c0, IDENTIFY slate #455a64, PROTECT lighter blue,
  DETECT amber #ffa000, RESPOND rust #d84315, RECOVER cream #fff8e1 (dark text).
