PCRs are extend-only
A measurement never overwrites a register: PCR = hash(PCR ‖ new). Each stage extends the value, so one tampered component permanently changes the final PCRs. Nothing rewinds a PCR except a reboot.
Real systems use BOTH
Secure Boot prevents bad boots; Measured Boot proves what booted. Enforcement stops an unsigned bootloader; attestation lets a remote verifier decide whether to trust the machine.
