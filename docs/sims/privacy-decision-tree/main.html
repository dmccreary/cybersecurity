Each branch maps to a privacy principle. "Do we need it?" is purpose limitation; "less identifying data?" is data minimization; "minimum retention" is storage limitation; and "lawful basis + DPA" is the lawful-basis requirement for sharing. These principles appear in both the GDPR and the CCPA/CPRA. Hover a node for the specific principle it enforces.
